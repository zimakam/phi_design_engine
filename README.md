## Что это

**φ-Design Engine** — движок генерации визуальных форм на основе:
- Золотого сечения
- Fibonacci-последовательностей
- Вихревой динамики
- Merkaba-геометрии

## 12 генераторов

1. `phi_spiral` — логарифмическая φ-спираль
2. `fibonacci_vortex` — кривая Γ(r) с φ-модуляцией
3. `merkaba_crystal` — 8 слоёв встречного вращения
4. `fibonacci_tree` — дерево с длинами ∝ F_k
5. `tesseract_projection` — 4D-гиперкуб в 2D
6. `koch_snowflake` — фрактал Коха
7. `fibonacci_phyllotaxis` — семена подсолнуха
8. `vortex_lattice_design` — решётка 13 вихрей
9. `phi_flower` — 3D-цветок из φ-лепестков
10. `merkaba_3d` — 3D-кристалл Меркабы
11. `vortex_field` — визуализация поля
12. `fractral_lattice` — самоподобная решётка
